# Contributing to GAMEROOM

Thanks for helping make GAMEROOM more fun!

## Easy ways to help
- Open an issue to suggest a game, feature, or improvement.
- Report bugs with the steps to reproduce them and the browser/device you used.
- Improve wording, accessibility, mobile controls, or documentation.
- Submit a pull request with a new original mini-game or a fix.

## How to contribute code
1. Fork this public repository.
2. Create a branch for your change.
3. Make your changes and test the site on desktop and a narrow/mobile screen.
4. Keep games free to play, lightweight, and usable with keyboard or touch where practical.
5. Open a pull request and explain what changed and how you tested it.

## Game and code guidelines
- Submit original code and assets, or materials that you have permission to use.
- Do not add ads, trackers, paid gates, malware, or requests for personal information.
- Do not commit passwords, API keys, tokens, or other secrets.
- Avoid external libraries unless they are necessary; explain any new dependency.
- Make controls accessible: clear instructions, visible focus, readable contrast, and touch-friendly targets.
- Test new games and make sure existing games still work.

## Review
Pull requests may be reviewed, revised, or declined before they are merged. Please be respectful and constructive in issues and discussions.

By submitting a contribution, you confirm that you have the right to submit it under the repository's existing license.
